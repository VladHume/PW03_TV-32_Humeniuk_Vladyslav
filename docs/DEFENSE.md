# Підготовка до захисту практичної 3

MonitorApi — контракт Retrofit із login, register і measurements. Gson перетворює JSON на DTO. За замовчуванням DemoApiInterceptor повертає відтворювані HTTP-відповіді без зовнішньої мережі. Є окремий локальний HTTP-сервер і тест MockWebServer, тому JSON і заголовки перевіряються також через справжній HTTP. Repository додає Bearer-токен через interceptor і записує отримані дані у Room — це локальний кеш. Сеанс має role та expiresAt. Помилки проходять через централізований task; тимчасові IOException/HTTP 5xx допускають до трьох спроб, 4xx не повторюються.

## Демонстрація

1. Увійди оператором, виконай синхронізацію, знайди отримані записи у журналі.
2. Обери HTTP 503 і повтори запит: покажи повідомлення; поверни «Успіх».
3. Обери завершений сеанс: захищений запит має вимагати нового входу.
4. Увійди viewer@demo.ua: кнопки створення й редагування недоступні.
5. Покажи server/demo_server.py і HttpIntegrationTest; поясни різницю між mock і локальним HTTP.

## Можливі питання

### Навіщо Repository?

UI не має знати, звідки дані: Room чи Retrofit. Repository перевіряє та узгоджує їх, а ViewModel керує сценарієм.

### Що таке Bearer-токен?

Значення в заголовку Authorization, яке сервер перевіряє перед доступом. Сам факт наявності заголовка не доводить правильність токена.

### Це production-автентифікація?

Ні. Токен демонстраційний, роль і строк дії читаються явно, а серверний mock перевіряє виданий токен. Для реального сервісу потрібні серверна перевірка, захищене зберігання, управління сеансами й відповідна модель загроз.

### Чим відрізняються 401, 403 і 503?

401 означає проблему автентифікації, 403 — відсутність дозволу, 503 — тимчасову недоступність сервера. Тому повідомлення й рішення про повтор запиту різні.

### Чому не повторювати будь-яку помилку?

Неправильний пароль або некоректний JSON не виправляються самим повтором. Повторюємо обмежено тільки тимчасові збої; операції зі зміною стану потребують окремої уваги до ідемпотентності.

### Що відбувається без інтернету?

Автономний mock не потребує мережі. Для зовнішнього API перевіряється підключення; раніше збережені записи Room залишаються доступними.

### Що записується до журналу помилок?

Час, клас помилки та HTTP-код. Пароль і токен не записуються. Файл errors.log міститься у приватному сховищі застосунку.

## Вправа

Поясни, скільки спроб буде для HTTP 503 і для 401. Додай тест одного з цих сценаріїв, не змінюючи очікування під фактичний неправильний результат.
